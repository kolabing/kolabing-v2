| BE-FX-17 | **Every hand-written JSON-LD block on the marketing site was invalid — Blade ate the `@context` key.** Laravel 12 ships an **`@context` Blade directive** (for the Context facade), and Blade compiles directives inside `{!! !!}` echo expressions. Four templates built their schema inline as `{!! json_encode(['@context' => 'https://schema.org', …]) !!}`, so the literal `'@context'` was replaced with compiled PHP and the emitted object's first key became `"<?php $__contextArgs = []; if (context()->has(…)) …?>"`.
